# 过程

过程包括四个概念：工作流、工作步骤、工作任务、工作记录。

## 基本概念

**工作流（Workflow）**：过程的定义，是行程的声明——一串有序的步骤，写明每一步谁做与怎么算完。一份定义可以起多项工作任务。

**工作步骤（WorkStep）**：工作流里的一站：一枚全局凭证、一个站名、一句指令。先声明后执行，声明了才有资格出现在流水里。

**工作任务（WorkTask）**：过程的执行，是一项行程的封面——一张账本，封皮上写着走哪条工作流，内页是流水。

**工作记录（WorkRecord）**：工作任务流水里的一条：什么时候、哪一站、一句话、过没过。只增不改，一条记一件事。

工作流与工作步骤在声明侧，说打算；工作任务与工作记录在事实侧，说交代。工作任务以流水对照所引定义逐站对账，走到哪一步由推导得出。四项均归属于某一具体工作区。
