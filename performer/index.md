# 执行者

执行者（Performer）是量潮知识工作规格的组成部分之一，回答**这一步由谁做、由谁判**。本文档定义执行者的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

执行者组描述工作的承担者，包括三类：

- 人类（Human）：由人来做、由人放行，留给人拍板的事项；
- 智能体（Agent）：由智能体照判准做、照判准审；
- 规则引擎（RuleEngine）：由程序当场核，机械比对，判法由平台定。

三类为并行的承担者：工作流里每一步带一个 `executor`，取三类之一，答这一步由谁做、由谁判。执行者内嵌于工作步骤，不独立成资源。

## 领域事件

执行者无独立的领域事件——它随工作步骤的声明而定，不单独变动。

## API 规格

执行者作为值对象内嵌于工作步骤，不单独暴露端点；读写随工作流定义一并进行。
