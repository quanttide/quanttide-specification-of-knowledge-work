# 工件

工件是量潮知识工作规格的组成部分之一，回答**工作以什么为对象**。本文档定义工件的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

工件组描述知识工作中的操作对象，包括两类：

- 材料（Material）：知识工作的输入，是工作开始前已有的内容；
- 产物（Artifact）：知识工作的输出，是工作流执行后生成的内容。
 
材料与产物为先后衔接的两类对象：材料经由工作流的处理转化为产物；产物在被验收前承载工作成果，验收后即完成其使命。材料、产物均归属于某一具体工作区。

## 领域事件

本组模型的主要领域事件是与材料和产物相关的生命周期事件，如材料的收录，产物的生成与验收等。

这些事件与其他各组事件存在先后关联：材料的相关事件先于工作流与工单的相关事件发生；产物的相关事件则后于工单的相关事件发生——产物由工单的执行生成，产物的验收是整个事件链的终点。

## API 规格

材料与产物作为领域实体均建模为 REST 资源，通过标准 HTTP 方法暴露端点。各端点的详细定义见 API 规格明细。
