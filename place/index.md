# 场所

场所（Place）是量潮知识工作规格的组成部分之一，回答**工作发生在哪里**。本文档定义场所的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

场所组描述工作发生的场所，包括两个层级：

- 工作台（Workbench）：对工作区的逻辑聚合层，负责跨工作区的导航、状态汇总与协同调度；不包含执行能力，执行由各工作区承载；
- 工作区（Workspace）：围绕特定目标形成的自包含执行环境，封装了任务流、工具集、信息资产与协作关系；工作台的基本组成单元；
 
工作台与工作区为一对多的层级关系：工作台不直接承载工件与过程，而是通过工作区间接组织它们。

## 领域事件

本组模型的主要领域事件是与工作台和工作区相关的生命周期事件，如工作台与工作区的创建等。

这些事件与其他各组事件存在前置关联：工作区的相关事件通常先于其他各组事件发生——材料、工作流、工单、产物均承载于工作区之内，工作区的存在是它们得以产生的前提。
 
## API 规格

工作台与工作区作为领域实体均建模为 REST 资源，通过标准 HTTP 方法暴露端点。各端点的详细定义见 API 规格明细。
