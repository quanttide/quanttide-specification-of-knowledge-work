# 场所

场所（Place）是量潮知识工作规格的组成部分之一，回答**工作发生在哪里**。本文档定义场所的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

场所组描述工作发生的场所，包括两个层级：

- **工作台**：组织级的共享工作场所，是工作区的容器，同一组织内包含若干工作区；
- **工作区**：材料、产物、工作流、任务等的实际承载空间。
 
工作台与工作区为一对多的层级关系：工作台不直接承载工件与过程，而是通过工作区间接组织它们；材料、产物、工作流、任务必须归属于某一具体工作区，工作台则为其提供组织级的共享与汇总能力。

## 领域事件

本组模型的主要领域事件是与工作台和工作区相关的生命周期事件，如工作台与工作区的创建等。

这些事件与其他各组事件存在前置关联：工作区的相关事件通常先于其他各组事件发生——材料、工作流、任务、产物均承载于工作区之内，工作区的存在是它们得以产生的前提。
 
## API 规格

工作台与工作区作为领域实体均建模为 REST 资源，通过标准 HTTP 方法暴露端点。各端点的详细定义见 API 规格明细。
