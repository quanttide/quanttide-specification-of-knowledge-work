# 工作区

工作区（Workspace）是一次工作的边界：它把一套工作流定义与其上下文内的工件绑定为独立单位。

工作区内，工件与过程互相可见、可流转；工作区之间彼此隔绝。

## 布局

工作区是一个根目录：

```
<根>/workflows/    工作流定义
<根>/tasks/        任务
<根>/artifacts/    产物
```

任务文件不写工作区在哪；它在谁的工作区里，就按谁的根算。

## 工作区的操作

三件事跨了定义、任务与工作区的现场，因此是工作区的操作：

- 核对：判据引用的路径在不在、描述提到的小节有没有覆盖；
- 落点：产物落在哪；
- 流水判定：步骤走没走过。

定义只声明要核什么。「在不在」由端侧判断，工作区不读文件系统。

## 与工作台

工作台（Workbench）呈现一个或多个工作区，是执行过程的台面。工作区是边界，工作台是台面。
