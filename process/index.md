# 过程

过程（Process） 是量潮知识工作规格的组成部分之一，回答**工作如何进行**。本文档定义过程的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

过程描述知识工作的执行方式，分定义与执行两侧：

- 工作流（Workflow）：行程的声明，由工作步骤（WorkStep）编成，写明每一步谁做与怎么算完；
- 工单（WorkOrder）：行程的账本，引用一条工作流，以只增不改的工作记录（WorkRecord）逐站记账。

工作流与工单为定义与执行的关系：工作流声明做什么与按何种顺序做，工单以流水对照定义逐站对账，走到哪一步由推导得出。工作流与工单均归属于某一具体工作区。

## 领域事件

本组模型的主要领域事件是与工作流和工单相关的事件，如工作流的创建、工单的创建、工作记录的追加等。

这些事件与其他各组事件存在前后衔接的关联：工作流的相关事件位于材料的相关事件之后、产物的相关事件之前；工单的相关事件则直接衔接产物的生成——产物由工单的执行生成。

## API 规格

工作流与工单作为领域实体均建模为 REST 资源，通过标准 HTTP 方法暴露端点。各端点的详细定义见 API 规格明细。
