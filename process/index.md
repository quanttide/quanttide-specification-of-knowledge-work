# 过程

过程（Process） 是量潮知识工作规格的组成部分之一，回答**工作如何进行**。本文档定义过程的通用语言、领域模型、领域事件与 API 规格。

## 领域模型

过程描述知识工作的执行方式，包括两个层级：

- 工作流（Workflow）：知识工作的执行方案，定义工作如何分步骤展开，是抽象层面的编排；
- 任务（Task）：工作流的具体执行实例，承载实际发生的操作，是具体层面的活动。
 
工作流与任务为抽象与具体的关系：工作流定义做什么与按何种顺序做，任务则将方案落实为实际的执行；任务必须对应于某一具体工作流，工作流则通过任务的执行得以实现。工作流归属于某一具体工作区。

## 领域事件

本组模型的主要领域事件是与工作流和任务相关的生命周期事件，如工作流的创建，任务的启动与完成等。

这些事件与其他各组事件存在前后衔接的关联：工作流的相关事件位于材料的相关事件之后、产物的相关事件之前；任务的相关事件则直接衔接产物的生成——产物由任务的执行生成。

## API 规格

工作流与任务作为领域实体均建模为 REST 资源，通过标准 HTTP 方法暴露端点。各端点的详细定义见 API 规格明细。
