# 任务

任务（Task）是过程的一次执行实例。

任务有指令：它定义对工件的一次加工。任务在执行中有状态，由人或系统推进，直至交付对应的工件。

## 语法

任务是一份 YAML，落在数据仓的 `tasks/<任务>.yaml`，一个任务一个文件，文件名即任务名。

```yaml
name: 任务名
start: 2026-09-10 22:31
workflow: 工作流名
log:
  - at: 2026-09-10 22:32
    step: 步骤名
    detail: 一句话
    ok: true
```

字段：`name`、`start`、`workflow`、运行上下文（`root` / `data` / `workflows`）、`log`（流水）、`gates`（闸门项）、`products`（这次执行往哪写产物，可省）。

`workflow` 指向它执行的工作流，是任务与工作流之间唯一的链接；`start` 记开工时间。

流水一条四项：`at` 时刻、`step` 步骤名、`detail` 一句话、`ok` 是否成功。流水只增不改；步骤是否走过，由流水读出——执行过且成功的步骤算走过。等人拍板的事项记在 `gates` 里。

任务是运行数据，不是产物：报告、日志这些产物与任务没有从属关系——一次执行可以一份产物都不出，一份报告也可以汇总几件事。程序只维护任务文件，不往产物里写字。

产物写在哪由 `products` 声明（`report: <路径>`、`journal: <路径>`）；写了路径，程序就按它在起任务时备好空骨架、并把判据里的 `{{report}}` 一类占位换成它；没声明就不建产物。写产物内容的是人或智能体，不是程序。
