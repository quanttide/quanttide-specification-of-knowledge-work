# 任务

任务（Task）是过程的一次执行实例。

任务有指令：它定义对工件的一次加工。任务在执行中有状态，由人或系统推进，直至交付对应的工件。

## 语法

任务是一份 YAML，落在数据仓的 `tasks/<任务>.yaml`，一个任务一个文件，文件名即任务名。

```yaml
name: 任务名
start: 2026-09-10 22:31
workflow: 工作流名
log:
  - at: 2026-09-10 22:32
    step: 步骤名
    detail: 一句话
    ok: true
```

四个字段：`name`、`start`、`workflow`、`log`。`workflow` 指向它执行的工作流，是任务与工作流之间唯一的链接；`start` 记开工时间；`log` 记流水。

流水一条四项：`at` 时刻、`step` 步骤名、`detail` 一句话、`ok` 是否成功。流水只增不改；步骤是否走过，由流水读出——执行过且成功的步骤算走过。

任务交付的产物按类型分家落在 `artifacts/`：报告 `report/<任务>.md`、日志 `journal/<任务>.md`。报告由程序维护「执行记录」与「闸门项」两节，其余各节归人；日志是叙事，由人写。
