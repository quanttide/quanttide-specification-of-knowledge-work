# 工作订单

工作订单（WorkOrder）是过程的执行档案：一条工作流跑一遍留下的全部记录。一份定义可以起多件工单，工单照着它走一遍（见 [工作流](./workflow.md)）。

## 领域属性

### 字段

工单落成一份 YAML 文件，文件名即工单名：

- `id`（UUID，只读）：唯一标识，在其所属工作区内唯一。
- `workflow_id`（UUID，必选）：照哪条工作流走，**按名字**引用，不存路径。
- `start`（String，必选）：从哪一步开工，须是所引工作流里的步骤名。
- `log`（List，推荐）：流水，只增不改，一条记一件事。
- `log[].at`（String，必选）：什么时候。
- `log[].step`（String，必选）：哪一步。
- `log[].detail`（String，推荐）：一句话，记发生了什么，默认为空。
- `log[].ok`（Bool，推荐）：过没过，缺省 `false`——没记录“通过”，就当作没通过。
- `gates`（List，推荐）：闸门项，等人拍板的事项，去重记录。
- `artifacts`（Map，推荐）：落点声明，产物类型 → 相对落点。声明写成什么就是什么，只记意图，不保证产物已落盘。
工单**没有状态字段**：走到哪一步、过没过，一律拿流水对照所引工作流**推导**，推导在 [工作区](../place/workspace.md)。权威在流水里，不在工单的任何单个字段上。

### 关联

工单隶属工作区，按名字引用工作流（见 [工作流](./workflow.md)）。流水与落点在区内的哪里，由工作区算，工单本身不带位置——它在哪、产物落哪，都是推出来的。

账与货分离：流水与闸门是程序自己的账，产物是人（或智能体）写的货。程序只维护工单，不往产物里写字；产物也不替账本作证——验收时拿判据去核产物，拿流水去对定义，两条线各查各的。执行者无权把 `ok` 写成 `true` 来自我放行：程序跑到没把握的地方，挂闸门、停下来等人拍板。

### 约束

- 字段取值之外一律拒绝：出现不认识的字段、缺必填字段，均视为不合语法；
- `workflow` 引用的工作流须在区内存在，`start` 须是它的步骤名；
- 流水只增不改：对已有流水的修改、删除、重排，均视为违规——改结论的唯一方式是追加一条新流水，旧记录原样保留，“以最新一条为准”只是推导规则，不是销毁历史；
- 闸门去重：已在闸门里的事项不重复记；闸门放行后事项清除，但**放行这一步本身追加进流水**，签核动作也留痕；
- `artifacts` 里的落点是相对声明，绝对路径一律拒绝——不存在工单管不到的暗渠；
- `ok` 的取值来源只能是机械比对或人经闸门的放行，执行者自写自读无效——干活的人不能给自己签字。

## 领域事件

### 事件

- 工单已开立（`WorkOrderCreated`）
- 流水已追加（`JournalRecorded`）
- 闸门已挂起（`GateRaised`）
- 闸门已放行（`GateResolved`）
- 工单已归档（`WorkOrderArchived`）

### 约束

- 事件负载至少携带工单名与工作区 `id`，供下游投影、汇总与审计使用；
- `JournalRecorded` 只描述追加的那一条，不含全量流水——重建靠事件序列回放，不靠快照覆盖。
 
## API端点

工单建模为 REST 资源，端点挂载于工作区之下：定义认名字，跨区互不可见。

### 工单资源端点

- `POST /workspaces/{workspace_id}/workorders`：开立工单，指明工作流名与起点。
- `GET /workspaces/{workspace_id}/workorders`：列出工作区下的工单。
- `GET /workspaces/{workspace_id}/workorders/{name}`：读取单个工单，含全量流水。
 
### 子资源端点

流水与闸门是工单的账目，各自开口、口径收窄：
- `POST /workspaces/{workspace_id}/workorders/{name}/journal`：追加一条流水。**不设 PUT / DELETE**：流水只增不改，改历史的口子一个不开；
- `POST /workspaces/{workspace_id}/workorders/{name}/gates`：挂起闸门项，已有的不重复记；
- `POST /workspaces/{workspace_id}/workorders/{name}/gates/{index}/resolution`：人放行闸门。放行动作自身落一条流水。
 
### 约束

- 开立工单撞上区内同名即拒绝，不覆盖；
- 流水与闸口的写端点只接受追加与放行，其余动作一律拒绝；
- 落点声明里的绝对路径一律拒绝；
- 无状态、幂等键等 API 口径见 [工作区](../place/workspace.md)。
